# local-transcribe

Общий процесс BB: запись/ссылка → транскрипт со спикерами → итоги Markdown/PDF по запросу.

- Разработка, коммиты и push выполняются на Tru. Mac — исполнитель локального распознавания с GPU.
- Используй API обнаружения сервисов. По умолчанию предпочитай Mac; запасные исполнители задаются в вызове через fallback (self — машина исходного треда). Автоматически переходи только по этому списку и после подтверждённой недоступности/ошибки. При неизвестном состоянии уже запущенной задачи не запускай дубликат. Облачный ASR не подключай без выбранного пользователем сервиса.
- Общий навык: `bb-plugin/skills/local-transcribe/SKILL.md`. Полная инструкция: `docs/транскрибация-и-итоги.md`.
- Основной запуск: `python3 diarize_ms.py <audio> --out <transcript.txt>`. Вариант без спикеров — `transcribe.py`. Whisper выбирается только явно через `--engine whisper`.
- PDF собирай через `templates/md2pdf.sh`, чтобы сохранить нормализацию Markdown и оформление.
- Исходные записи не удаляй. Не коммить аудио, видео, модели, транскрипты встреч, секреты и кэши.
- Запрос «расшифруй» заканчивается транскриптом; запрос итогов включает Markdown и PDF. Имена людей не выводи из номеров спикеров без контекста.
- Проверки адаптера: `python3 -m unittest discover -p 'test_*.py' -v`. Для изменений оркестрации проверяй передачу файлов между машинами и возврат ошибки при недоступной машине.
