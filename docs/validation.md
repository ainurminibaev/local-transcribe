# Проверки реализации

Проверено 16.11.2026 на Apple Silicon Mac и Linux x86_64 / Python 3.12.

- Unit-проверки Python: GGUF-токены и таймкоды, отсутствие моделей, целостность кэша, повторная кластеризация без embeddings, малочисленный синтетический голос, остановка процесса по истечению lease и загрузка публичных весов с SHA-256.
- Unit-проверки плагина: порядок резервов, self/available, отмена, отсутствие второго запуска при кратком разрыве, переход после истечения lease, очередь, артефакты, запрет перезаписи и восстановление доставки без повторного ASR.
- WAV → Mac → транскрипт со спикерами → Tru; WebM → текст + JSON + M4A + побайтово неизменённый исходник. Примеры кластеров сформированы в ZIP.
- Передача 2,5 MB в несколько порций туда и обратно с совпадением SHA-256; существующее другое содержимое не заменяется.
- Скачивание по HTTP и извлечение MP3 проверены на локальном тестовом сервере; доступ ко всем сайтам/закрытым URL этим не подтверждается.
- Markdown → PDF с кириллицей, списками и таблицей; сборка на Mac и возврат PDF на Tru. Текст PDF проверен через pypdf.
- На Mac журналы подтвердили MPS для speaker embeddings и Metal для GigaAM. На Tru установлен отдельный CPU-venv и выполнено полное распознавание синтетической записи.
- Публичные ModelScope runtime-файлы скачаны в чистую временную папку по официальным URL и сверены с манифестом. На Linux сохранён проверенный lock-файл зависимостей.

Практическое ограничение: на длинной реальной встрече автоматическая оценка слила пять участников в два кластера. Поэтому число кластеров не выдаётся за число людей; добавлены известное число спикеров, кэш и примеры для проверки. Ограничение 5 не заменяет прослушивание и контекстную проверку личностей. Физическое закрытие крышки ноутбука не использовалось как тест: истечение lease и пробуждение после дедлайна проверены моделированием времени и остановкой дочернего процесса.

Повторить проверки:

```sh
python3 -m unittest discover -p 'test_*.py' -v
python3 scripts/sync_bb_skill.py --check
cd bb-plugin
npm ci --ignore-scripts
bb plugin build .
npm test
```

Личные записи, транскрипты, голосовые примеры и рабочие job ID в этот документ и Git не включаются.
