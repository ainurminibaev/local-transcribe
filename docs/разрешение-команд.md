# Разрешение команд (allow-лист) — пайплайн без переспросов

Чтобы пайплайн «скачать → транскрибировать со спикерами → собрать итоги.md + итоги.pdf» прогонялся end-to-end **без запросов на подтверждение**, нужно один раз разрешить рутинные команды в `.claude/settings.local.json` того проекта, где лежат записи.

## Куда класть

Файл `.claude/settings.local.json` в **корне рабочего проекта** (рядом с записями), не в репозитории кода. Структура:

```json
{
  "permissions": {
    "allow": [
      "..."
    ]
  }
}
```

## Готовый блок правил для пайплайна

Скопировать в массив `permissions.allow`. Правила wildcard (`:*`) покрывают любые аргументы соответствующей команды:

```jsonc
// --- скачивание ---
"Bash(yt-dlp:*)",
"Bash(python3 /Users/example/.claude/commands/video-downloader/scripts/download_video.py:*)",
"Bash(python3 scripts/download_video.py:*)",

// --- извлечение/конвертация аудио ---
"Bash(ffmpeg:*)",
"Bash(ffprobe:*)",

// --- транскрибация со спикерами (путь к diarize_ms.py) ---
"Bash(python3 ~/local-transcribe/diarize_ms.py:*)",
"Bash(python3 /Users/example/local-transcribe/diarize_ms.py:*)",

// --- сборка PDF ---
"Bash(pandoc:*)",
"Bash(weasyprint:*)",
"Bash(export DYLD_FALLBACK_LIBRARY_PATH=/opt/homebrew/lib:*)",

// --- файловая рутина ---
"Bash(mkdir:*)",
"Bash(mv:*)",
"Bash(cp:*)",
"Bash(cd:*)",
"Bash(ls:*)",
"Bash(cat:*)",
"Bash(head:*)",
"Bash(tail:*)",
"Bash(wc:*)",
"Bash(grep:*)",
"Bash(awk:*)",
"Bash(sed:*)",
"Bash(echo:*)",
"Bash(mdls:*)",

// --- точечные удаления (временные файлы) ---
"Bash(rm -f .style.css)",
"Bash(rm -f download.log)",
"Bash(rm -f raw/download.log)"
```

Заменить `<you>` на своё имя пользователя. Пути к `diarize_ms.py` оставлены в двух вариантах (`~` и абсолютный) — Claude Code матчит правило по точной форме команды.

## Важные нюансы

- **Каждую команду запускать отдельным простым вызовом.** Составные команды (через `;`, `&&`, `|`, `>`) Claude Code всегда выносит на подтверждение, даже если каждая часть уже в allow. Это главная причина «опять спросил». Пример: `cd …; export …; pandoc … | tail; rm …` → спросит. Разбивать на отдельные вызовы: `cd`, `pandoc …` (без `| tail`), `rm -f .style.css`.

- **`rm:*` целиком НЕ открывать.** Удаление/перезапись исходников (видео, дубли) — по правилам уборки только с подтверждением пользователя и только после того, как аудио создано и проверено (см. `уборка.md`). В allow держать лишь точечные `rm -f <временный файл>`.

- **Не использовать интерактивный опрос для выбора действия.** Присланная ссылка/запись = команда прогнать весь пайплайн до `итоги.pdf`. Уточнять только если файл битый или физически нельзя продолжить.

- **Глобальные vs локальные настройки.** Кладите правила в локальный `settings.local.json` проекта. Общие для всех проектов вещи можно вынести в `~/.claude/settings.json`, но пути к записям всегда индивидуальны.
