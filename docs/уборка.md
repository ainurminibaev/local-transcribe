# ИНСТРУКЦИЯ — уборка и экономия места

Папка Telemost копит тяжёлые видеозаписи встреч (`.webm`/`.mp4`). **Видео нам не нужно вообще** — для работы достаточно звука: из аудио всегда можно расшифровать. Поэтому из любого видео извлекаем аудио, а само видео удаляем. Эта инструкция описывает безопасную процедуру.

## Когда применять
После завершения **любой** задачи в этой папке — кратко предложить пользователю уборку (см. правило в `CLAUDE.md`, раздел «Уборка и экономия места»). Предложение — одна строка: что можно убрать и сколько МБ освободится.

## Что и при каких условиях трогаем

| Объект | Условие | Действие |
|---|---|---|
| Видео `.webm`/`.mp4` (в первую очередь **> 100 МБ**) | Нет активной транскрибации этого файла | Извлечь аудио → удалить видео (с подтверждения). Транскрипт иметь НЕ обязательно — аудио сохраняем как источник |
| Любой файл | Идёт активная транскрибация (`pgrep` ниже) | **НЕ трогать** до завершения |
| Аудио `.m4a`/`.mp3` | — | Не трогаем (уже лёгкие, это и есть наш источник) |
| `*.log`, временные `*.wav`, распакованные промежуточные файлы | — | Предложить удалить |
| Дубли (одинаковый файл в корне и в подпапке встречи) | — | Предложить удалить копию из корня |

## Совместимость с пайплайном транскрибации (важно — не сломать процесс)
- `diarize_ms.py` принимает **и видео, и аудио** одинаково (внутри всё равно конвертирует через ffmpeg в wav). Поэтому замена `recording.webm` → `recording.m4a` пайплайн **не ломает** — расшифровать можно ровно так же.
- Конвенция файла записи в папке встречи допускает `recording.webm` **или** `recording.m4a` — что осталось после уборки, то и есть исходник.
- **Никогда не убираться во время активной транскрибации.** Перед любой уборкой проверить, что процессов нет:
```bash
pgrep -fl "diarize|transcribe|whisper-server|ffmpeg"   # пусто = можно убираться
```

## Шаг 1. Диагностика (сколько и что весит)
```bash
cd "~/Documents/Yandex Telemost"
# Видео крупнее 100 МБ во всём дереве проекта:
find . -type f \( -iname '*.webm' -o -iname '*.mp4' \) -size +100M -exec du -h {} \; | sort -rh
```
Для каждого кандидата проверить, есть ли рядом транскрипт (`transcript.txt` в той же подпапке или одноимённый `*.txt` в корне).

## Шаг 2. Извлечь аудио (без перекодирования видео-дорожки — просто отбрасываем видео)
```bash
ffmpeg -i "ВИДЕО.webm" -vn -c:a aac -b:a 96k "ВИДЕО.m4a"
```
- `-vn` — выбросить видео-дорожку.
- `-c:a aac -b:a 96k` — речь в 96 kbps AAC (с запасом по качеству для распознавания; обычно ужимает в 20–50× от исходного видео).
- Если в исходнике аудио уже в удобном кодеке — можно `-c:a copy` (без перекодирования, мгновенно).

## Шаг 3. Проверить аудио и удалить видео — ТОЛЬКО с подтверждения
```bash
ls -lh "ВИДЕО.m4a"            # убедиться, что аудио создалось и ненулевое
# afplay "ВИДЕО.m4a"          # при желании — послушать кусок
rm "ВИДЕО.webm"               # только после явного «да» от пользователя
```

## Жёсткие правила безопасности
- **Деструктив (удаление/перезапись) — только после явного подтверждения пользователя.** Никогда не удалять видео «по умолчанию».
- Не удалять видео, у которого **нет** транскрипта.
- Сначала создать и проверить аудио, **потом** удалять видео. Не наоборот.
- Сообщать фактический результат: сколько МБ освобождено, какие файлы остались.
